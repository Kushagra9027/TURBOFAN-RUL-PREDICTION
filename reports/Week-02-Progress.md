# Week 02 Progress Report

## Project

Predicting Remaining Useful Life (RUL) of Turbofan Engines

## Duration

Week 02

---

## Objectives for Week 02

The primary objective for this week was to perform detailed Exploratory Data Analysis (EDA) on the NASA C-MAPSS FD001 dataset and gain a deeper understanding of engine degradation behavior before beginning machine learning model development.

---

## Activities Completed

### 1. Dataset Exploration

* Loaded the NASA C-MAPSS FD001 dataset into the development environment.
* Examined dataset dimensions, structure, and feature descriptions.
* Verified data types and dataset consistency.
* Analyzed statistical summaries of operational settings and sensor measurements.

### 2. Data Quality Assessment

* Performed missing value analysis.
* Verified dataset completeness.
* Confirmed that the dataset did not contain significant missing values requiring preprocessing.

### 3. Engine Lifecycle Analysis

* Investigated engine operational cycles.
* Calculated engine lifetimes using cycle information.
* Generated engine life distribution visualizations.
* Studied degradation behavior across multiple engines.

### 4. Remaining Useful Life (RUL) Analysis

* Generated Remaining Useful Life (RUL) labels for training data.
* Verified RUL calculations using engine life cycle information.
* Explored RUL distribution across the dataset.
* Studied how RUL decreases as engines approach failure.

### 5. Correlation Analysis

* Generated correlation heatmaps for operational settings and sensor measurements.
* Investigated relationships among features.
* Identified features potentially relevant to engine degradation.

### 6. Sensor Trend Analysis

* Analyzed behavior of selected sensors across operational cycles.
* Generated sensor trend visualizations.
* Investigated sensor degradation patterns over time.
* Observed changes in sensor readings as engines approached failure.

---

## Key Observations

* Engine degradation follows measurable trends that can be observed through selected sensor measurements.
* Several sensors exhibit noticeable changes as Remaining Useful Life decreases.
* Correlation analysis indicates that some features may be more informative than others for future prediction models.
